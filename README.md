# Quick Record v0.1

手机收支记账网站，无第三方依赖。默认打开“首页”，数据保存在当前浏览器的 IndexedDB 中。

## 使用与发布

直接双击 index.html 即可在浏览器预览，无需启动服务；请保留同目录下的脚本、样式和图标。文件模式不注册离线缓存，页面资源直接从磁盘加载。离线缓存安装需要 localhost 或 HTTPS。文件模式的存储支持取决于浏览器，且与 HTTP/HTTPS 网站的账单不互通；移动文件后请先确认原账单是否仍可访问。将本目录应用文件发布到 GitHub Pages，在 iPhone Safari 打开并添加到主屏幕。无需构建。已于2026-10-19发布到 GitHub Pages。

第一次联网打开并显示“离线资源已准备好”后，可离线使用。更新应用时同时修改 sw.js 的 CACHE 版本；新版会在旧页面全部关闭后接管，不修改账单库。

账单顶部有横向日期时间轴，一屏完整显示七天，顶部月份可点击选择目标月份，默认选择今天。左右滑动时使用系统惯性滚动，减速后吸附居中日期，停稳后显示该日账单；电脑可按住鼠标左键拖动，松开后按速度平滑减速并吸附，拖动不会误触日期按钮；点击日期也可定位，通过继续横向滑动跨月查看更早记录，不显示月份箭头；日期上方灰色竖线以居中最高、向两侧逐级变短排列。组头显示黑色粗体日期，每条账单仅显示时间。右上角“…”→“编辑”可进入逐条编辑模式；点击账单旁“编辑”可修改金额、分类、收支类型及年月日。保存保留原ID与原时分秒，按所选日期更新记录，并重新计算统计，取消不改动账单。编辑状态下右上角直接显示“完成编辑”，点击即可退出并恢复“…”按钮。已按要求移除导出与恢复入口；现有本地账单不会删除，清理浏览器网站数据会丢失本地账单。

## 发布到 GitHub Pages

当前项目与 GitHub 上的旧版 `iuggs4/personal-ledger` 独立，使用独立公开仓库 `iuggs4/quick-record` 发布。旧版使用 localStorage，本项目使用 IndexedDB，两版账单不会自动迁移；本地文件预览中的账单也不会自动带到线上地址。

网站无需构建或业务后端。仓库提交程序、图标和文档；`.gitignore` 排除本机 Codex 配置，`.nojekyll` 让 Pages 直接发布静态文件。发布资源必须包含 `index.html`、`style.css`、`app.js`、`model.js`、`storage.js`、`calendar.js`、`templates.js`、`sw.js`、`manifest.webmanifest` 和 `icon.png`。

仓库：[iuggs4/quick-record](https://github.com/iuggs4/quick-record)。在线网站：[Quick Record](https://iuggs4.github.io/quick-record/)。Pages 发布源为 `main` 分支的 `/ (root)`，已启用 HTTPS。在 iPhone Safari 打开在线网站并添加到主屏幕即可使用。后续推送到 `main` 会触发重新发布。

2026-10-19 已上传并启用 Pages；线上首页和8项发布资源均确认HTTP 200，首页标题为 Quick Record。未执行本地功能测试或 iPhone 实机验证。操作说明参考 [GitHub Pages 官方文档](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site)。

## 开发接口

model.js：金额、日期、账单和模板校验；storage.js：账单与模板事务存储；calendar.js：消费日历聚合和呈现；templates.js：常用模板交互；app.js：页面、系统数字键盘输入、分类、外观和账单编辑；sw.js：离线缓存。

`window.Ledger.readBills()` 返回账单副本；`addBill(bill)` 经统一校验写入，成功后安排刷新当前可见页面并返回存储结果，写入失败不触发刷新；`register({id, slot, mount})` 注册随应用发布的模块。slot 为 home-cards、form-extra、bill-actions、more-menu；mount 接收容器和 Ledger 接口。扩展没有安装或远程加载机制。

扩展只允许随应用发布并经过审查的受信任代码。注册校验和 Object.freeze 是接口约定，不构成安全隔离；同页面模块仍可访问 DOM、全局存储和 IndexedDB。第三方或远程代码不能直接接入并宣称已隔离。

账单格式：id 字符串、amount 正整数分、category 固定分类、createdAt ISO 时间字符串，type 为 expense 或 income；旧记录无 type 时按支出处理。内部备份结构校验仍识别旧版1和新版2，当前界面不提供导出或恢复操作。点击底栏加号从底部打开 Quick Add 面板，通过 Expend / Income 滑块分别保存支出与收入，日期默认今天且可另选；新增按所选日期及保存时刻记账；切换收支类型或关闭面板会清空未保存金额并显示0.0，分类保留；收入计入首页 Income 和钱包余额，不计入支出柱状图及当天花费概览。

金额、备份、记账面板交互及页面读取用例位于 tests/model.test.js；连接生命周期和事务冲突用例位于 tests/storage.test.js；日历和模板交互分别位于 tests/calendar.test.js、tests/templates.test.js，npm test 会运行四个文件。本轮10个JavaScript文件的 node --check 语法检查与 git diff --check 静态检查通过，这不等于功能测试。按用户要求，本次未执行自动测试、浏览器验收或 iPhone 实机验证，未测试；模拟 DOM、IndexedDB 及独立时区用例不能替代真实浏览器验收。

从后台返回或触发 pageshow 时会合并刷新当前页面，账单页保留选中的历史日期。每分钟只做跨天检查，不按分钟全量读取。首页和账单页均只采用最新读取请求的结果，区分读取中、暂无账单和读取失败，并提供“重试”；保留旧内容时明确标注为上次读取结果，切换账单日期时先清除旧日期列表。读取提示支持读屏，账单时间轴不受提示位置影响。

2026-10-26 审查修复：数据库连接改为惰性、可重试，首次打开失败后再次读取会重新连接；blocked 请求迟到成功会关闭多余连接，版本变化或意外关闭后允许重连。编辑先按 ID 重新读取最新账单，再填表并建立原始快照；在同一写入事务中检查记录是否已改变，冲突或记录不存在时拒绝覆盖并保留输入。关闭后即使点击旧列表按钮，也会再次读取最新值；读取失败不使用旧记录打开面板。首页状态条固定在底栏上方，不占首页顶部布局；账单页提示仍位于时间轴下方。

新写入统一使用本地日期 0100-01-01 至 9999-12-31，时间轴与图表裁去边界外或本地不存在的日期。ISO 时间允许合法本地边界对应的 UTC 0099 年或 +010000 年；旧超范围记录不删除、不自动改期，修改时需选择支持范围内的日期。改期无法保留原时分秒时会拒绝保存。

单笔金额仍限定为安全整数分，最大 9007199254740991 分（90071992547409.91 元），输入与公开写入使用同一校验；显示和编辑按整数元与余分拼接，避免大金额改动一分。多笔合计仍可能超出安全整数范围，相关统计会明确报错，不截断或显示成零。首页每日分组只处理所展示的最近日期，早于展示范围的历史日汇总溢出不再阻断当前首页。切日和首页仍全量读取账本，未做性能测量；暂不增加日期查询索引或永久缓存。数据库本次升至版本2仅为新增模板仓库。
